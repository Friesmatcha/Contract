华东区域采购框架协议

鉴于甲方在华东区域开展业务的需要，乙方同意按照本协议约定的条款和条件向甲方提供相关产品及服务。双方本着平等自愿、互惠互利的原则，经友好协商，达成如下协议，以兹共同遵守。

第一条 合作范围与期限

1.1 本协议涵盖的产品和服务清单详见附件一。未经双方书面同意，任何一方不得擅自变更合作范围。

第二条 付款方式与周期

2.1 甲方应于收到乙方开具的合格发票后，按照双方确认的结算周期进行付款。

2.2 付款周期为：自甲方收到合规发票之日起，六十（60）个工作日内通过银行转账方式支付至乙方指定账户。如遇法定节假日，付款时间顺延。

2.3 若甲方逾期付款，每逾期一日，应按应付未付金额的万分之五向乙方支付违约金。但因乙方未按规定提供发票或提供的发票不合规导致的迟延除外。

第三条 质量保证与验收

3.1 乙方保证其提供的产品和服务符合国家相关标准及本协议约定的质量要求。
